# Mark I – Interactive Iron Man Suit

An interactive webpage inspired by **Iron Man’s Mark 1 suit**, built using **HTML, CSS, and JavaScript**.  
When you hover over the suit, it scales up and begins introducing itself with a **smooth typing animation**.

## 🚀 Features
- Interactive hover animation  
- Real-time typing text effect  
- Minimal white background for clean aesthetics  
- Fully responsive and lightweight  

## 🧩 Tech Stack
- HTML5  
- CSS3  
- JavaScript
